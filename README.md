# UVPdomain website

A static HTML/CSS site designed for GitHub Pages.

## Publish

1. Upload all files and folders to the root of your GitHub repository.
2. Open Settings → Pages.
3. Choose Deploy from a branch.
4. Select `main` and `/root`.
5. Save.

## First edits

- Replace `hello@example.com` and `licensing@example.com`.
- Replace `#` placeholder links with Bandcamp/Spotify links.
- Add artwork to the `images` folder.
- Replace artwork placeholder blocks with `<img>` elements.
